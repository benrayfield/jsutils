How the counters and modes work
Reference FLOPs count float arithmetic/Math operations (one each; add3 counts two), plus literal loads and named float reads (one per scalar). Loop counts and called functions are included. Integer bookkeeping, stack stores, canvas work and compilation are excluded. These are source-work units, not measured hardware instructions. The fastest manual mode skips work, so its count/rate is reference-equivalent. Inlining removes intermediate float32 rounding; packed colors can differ near fractal boundaries. The rate decays while idle. Display counters include completed pixels from cancelled frames; benchmark work is counted separately.


Compare all four modes on identical pixels.


Benchmark uses the bundled 64-iteration example and palette in every mode, at the current view/resolution; edits in the source box are excluded. Kernels are warmed and their order rotates. The table measures CPU calculation including stream I/O; canvas writes, scheduling and compilation are outside timing. × manual fixed is elapsed time divided by the hand-written fixed-work baseline. The fastest mode uses early exit and performs less work.

3 · Use the browser console
These are classic scripts. Open developer tools and use Stak directly:
const s = Stak.newStakStream(64);
const length3 = Stak.eval(`
WWWlength3_demoHashMBlok
	zW yW xW
	Mx Mx WWmulM
	My My WWmulM WWaddM
	Mz Mz WWmulM WWaddM
	WsqrtM
Kolb`);
s(3); s(4); s(0);
length3(s);
s(); // 5


Stak.newStakstream is an alias. s(value) pushes; s() pops. Every Stak function takes one stream argument. A push stores float32: 3.4 comes back as approximately 3.4000000953674316. Generated functions do not call Math.fround. The full corrected example bundle is available as StakExampleSource.


Tokens and current limits


xWBind one caller-supplied scalar parameter. No C1 and no M1 before it.


Mx M1 WWaddMRead x, push float one, add.


sumL · sumV · AsumReserve a local, write it, read it. Names are private to each function.


C6 valuesWBind a readonly six-float array. C is for integer sizes and indices.


C6 nextLReserve a local six-float array; initialize before reading.


Cindex J_values_MRead one element with a checked integer index.


M7 Cindex JW_next_Write seven into one local array element.


Ccount Loop iJ … PoolRepeat count times with a fresh immutable index for each iteration.


nameBlok … KolbDefine a function. Klob is accepted as an alias for Kolb.


Placeholder hashes are names, not verified content hashes. GLSL uses compile-time integer specialization for generic array sizes. It does not allocate dynamically sized GPU arrays. No source recursion, if/else or while. The compiler checks stack effects and array access. Generated calls use primitive locals and the supplied stream; parsing and code generation happen before execution. CPU math and shader math require numerical tolerances. No GPU slowdown factor has been established by these tests.
